Calagopus Panel is a modern, open-source game server management panel built in Rust. Deploy, monitor, and manage Minecraft, Rust, and other game servers through a responsive web interface. Similar to Pterodactyl in role, but written in Rust for superior performance.

This package installs the **Panel only** (web UI + API). To host game servers you will also need at least one **Wings** node connected to the panel.

**First-run:** After installation, open the panel URL in your browser to complete the Out-Of-Box Experience (OOBE) wizard and create your first admin account.

**Note:** YunoHost accounts are NOT linked to Calagopus accounts — Calagopus manages its own authentication independently.
